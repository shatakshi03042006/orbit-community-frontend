# ConnectPro Frontend Redesign

This revision applies a premium dark professional-community visual system with charcoal surfaces, violet accents, responsive layout, and updated navigation branding.

## API compatibility
- Kept the existing Axios instance and backend base URL unchanged.
- Kept existing React Router routes and API-driven page components in place.
- Kept existing API request code unchanged, including the post fetch and create calls and signup call.

## Run locally
1. Install Node.js (compatible with the versions specified by the project).
2. Run `npm install`.
3. Run `npm run dev`.

The archive intentionally excludes `node_modules` and `dist`; dependencies should be installed locally. This is a frontend visual redesign, not a backend rewrite. Existing placeholder profile information and any API behavior already present in the original source remain to be audited and connected where supported by the backend.
